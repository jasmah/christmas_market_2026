## 🚀 How to Publish on GitHub Pages
1. Push this repository to `https://github.com/jasmah/christmas_market_2026.git`.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment → Source**, select **Deploy from a branch**, choose **`main`** and **`/ (root)`**, and click **Save**.
4. Your family website will be live within 60 seconds at `https://jasmah.github.io/christmas_market_2026/`.
